CakBro

Safe Exam Browser v2.0 — Chromebook PWA

Halaman ini untuk instalasi di Chromebook. Di Windows/Linux/Mac, gunakan file .exe / .AppImage / .dmg dari folder dist/.

🚀 Buka Halaman Ujian
  1. Chromebook: Buka halaman ujian → klik ⋮ (tiga titik) di Chrome → Install app / Save and share → Install
  2. App akan terbuka fullscreen tanpa address bar (display: fullscreen)
  3. Untuk keluar: tutup app atau Ctrl+Alt+Shift+Q jika via Electron Linux
  4. Atau aktifkan Linux di Chromebook dan install versi .deb (lihat README): sudo apt install ./CakBro-*.deb

PWA sudah include manifest.json dengan display: fullscreen & scope ujian. Service worker memblokir translate popup via CSS injection.
