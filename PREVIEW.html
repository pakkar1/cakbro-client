🚀 Cara Build

  1. Install Node.js LTS lalu npm install di folder cakbro-app
  2. Jalankan dev: npm run dev (window biasa + DevTools) atau npm start (kiosk)
  3. Build: npm run build:win / build:linux / build:mac — hasil di dist/
  4. Otomatis semua OS: push ke GitHub → workflow .github/workflows/build.yml akan build 3 OS paralel
  5. Chromebook PWA: upload folder pwa/ ke hosting, buka di Chrome → Install
